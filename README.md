# SA\OS demo

A clickable front-end demonstration of **SA\OS** (Streets Ahead Operating System), the full-version product the Streets Ahead complaints proof-of-concept graduates to.

This is a static demo with fictional sample data only. No real data is shown. The first module, Complaints triage, is fully clickable; the wider platform (Operations, Compliance, People, Fleet Management, Business Intelligence) is shown as preview.

Built by Cloudheads.

## Run locally

```
python3 -m http.server 8000
```

then open http://localhost:8000/
